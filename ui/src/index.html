    Guide

    Help & About

    Practical guidance for creating, previewing, calibrating and exporting Lenticulizer projects.

    Quick Start

    A normal source-image project can be completed in this order.

    1. Add source images.Use 2 to 8 views. Their order controls which image appears as the viewing angle changes.
    2. Set the final print size.Choose the physical width, height, printer DPI and lens direction.
    3. Choose an optical settings mode.Automatic is the normal starting point. Semi-Automatic and Manual expose progressively more direct control.
    4. Generate the image pair.Lenticulizer creates the interlaced image and its matching 16-bit heightmap or depth map together.
    5. Inspect the preview.Use the image preview and Live 3D Preview to check cropping, orientation, order and the approximate viewing effect.
    6. Export or send to Blender.Export the finished image pair, or use Blender for more detailed optical and geometry inspection.
    Source images and view order

    For vertical lenses, source order represents left-to-right viewing. For horizontal lenses, it represents top-to-bottom viewing.

    Drag cards in the Images page to reorder them. The center image in an odd-numbered set is the straight-on view.

    If the wrong image appears from an angle, check the source order before changing optical settings.

    Automatic, Semi-Automatic and Manual

    Automatic uses recommended values for the current printer, image count and optical setup.

    Semi-Automatic keeps calculated behavior while allowing selected adjustments.

    Manual exposes supported optical and geometry values directly. Use it when you are matching a known physical setup or calibration result.

    LPI, DPI and build quality

    LPI is the number of lenticules per inch. Printer DPI controls the available raster resolution across those lenticules.

    Recommended presets choose compatible values automatically. Manual LPI is available when you need to match a known lens or measured print.

    Higher build detail increases the number of pixels used for each lenticule. It can improve fidelity but also increases processing and file size.

    Lenticular Lens and Lens-Free Relief

    Lenticular Lens creates a printed image plus clear lens geometry intended to refract between views.

    Lens-Free Relief creates directional prism or relief geometry without a separate clear lenticular layer.

    The required image ordering and height/depth output change with the selected mode and direction.

    Reference heightmap workflow

    Import a grayscale PNG or TIFF to inspect an existing lens or prism profile. Black represents zero height and white represents the entered white-level height.

    Verify the physical width, height and white-level height before building. A grayscale image alone cannot reveal its real-world dimensions or absolute height.

    When detection is uncertain, choose Manual and enter the lens direction, pixels per lens and registration yourself.

    Live 3D Preview

    Use the mouse to orbit, pan and zoom the preview. Front returns to the straight-on view. Left and Right change to Top and Bottom when horizontal lens direction is active.

    The desktop preview is intended for quick visual checking. Blender remains the more detailed geometry and optical inspection environment.

    Blender integration

    Sync to Blender sends the current project state to an already connected Blender project.

    Open current project in Blender opens the project using the supplied baseline scene and matching Blender add-on.

    The authored Blender workspace includes a selected-source viewer, interlaced viewer, height/depth-map viewer, primary 3D viewer and dedicated lens/prism inspection views.

    Close Project in the add-on disconnects live synchronization. Reconnect or open the project explicitly when you want to resume syncing.

    Calibration coupons

    Calibration coupons are small test prints used to compare thickness, viewing angle, alignment or lens profile before committing to a larger print.

    Use the current project settings as the starting point, print the generated set, then choose the result that gives the best physical viewing behavior.

    Exported files

    Interlaced image is the color raster sent to the printer.

    Heightmap / depth map is the matching geometry raster. Lenticulizer preserves the 16-bit heightmap output where applicable.

    Export both places the matched production pair in the same selected folder.

    Portable Blender package prepares a project package for Blender-based inspection and rendering.

    Troubleshooting

    Wrong image from an angle: verify source order and lens direction.

    Generated files look stale: use Generate / Regenerate Both after confirming the current settings.

    Blender is not updating: verify that the same project is connected and that Auto Sync is enabled when desired.

    Imported heightmap looks wrong: verify physical dimensions, white-level height and detected direction/pitch.

    Preview differs from print: use calibration coupons and Blender inspection to validate the physical setup.
